# Secretariat

Secretariat is Imperium's operator-facing administrative Office: its point of entry, question-and-response surface, and final delivery surface.

This directory gathers the current theoretical constituents of the Office:

- [`doctrine.md`](doctrine.md) — the Office's purpose, jurisdiction, responsibilities, boundaries, and handoffs.
- [`seat-resident-secretary.md`](seat-resident-secretary.md) — the Office-owned position through which Secretariat authority may be exercised.
- [`profile-secretary.md`](profile-secretary.md) — the installable qualification required for a generic Officer to occupy the Secretary Seat.

## Constituent distinction

```text
Secretariat ≠ Secretary Seat ≠ Secretary Profile ≠ Officer
```

Secretariat owns the Seat and the Profile. Conscription owns the generic Officer substrate, installs the Office-provided Profile, and spawns the resulting qualified Officer. The qualified Officer may exercise Secretariat authority only while occupying the Secretary Seat.

A runtime Secretary instance does not belong in this directory.
