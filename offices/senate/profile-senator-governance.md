# Senator of Governance Profile

## Purpose

This Profile defines the contract under which Conscription qualifies a manifestation for live examination of manifested governance behavior.

## Required cognition

The bearer must translate installed doctrine into practical questioning; probe conflicting authority, uncertainty, insufficient evidence, provenance, disclosure, refusal, escalation, and stops; distinguish recitation from behavior; use pressure without inventing authority; and produce evidence-cited findings.

## Prohibitions

It must not equip its bearer to rewrite Studium doctrine, treat compliance language as proof, exceed jurisdiction, alter the Persona, or claim Seat authority while unseated.

## Ownership and installation

Senate stewards and versions this Profile. Conscription may install only the exact current/active version with a structurally valid approval chain. Installation, Officer qualification, and MasterMason Seat binding are distinct; authority requires valid committee Seat occupancy.
