The worker rehashes actual loose SHA-1 commit/tree/blob objects. The test asserts exact object IDs,
committed bytes rather than uncommitted substitutions, byte SHA-256, three nonce consumptions and
unchanged hashes for every target file. Hostile Git remote/promisor/hooks/fsmonitor configuration

deployment isolation. It is not the quarantined real reference mission.

Limits: loose SHA-1 repositories only; no packed objects, worktree .git indirection, submodules or
symlink blobs. Targets must be on a local filesystem; UNC/URL inputs refuse. OS/network-mounted
volumes are a deployment assumption, not disproved by same-user local tests. `max_bytes` bounds
accepted inflated object content (including commit/tree metadata), with bounded compressed/header
parsing overhead. File/finding counts are checked before object reads. The parent kills the worker
at the time deadline, subject to OS scheduling and process-termination latency; no hard real-time
or hardware power-loss claim is made.

Independent-process tests cover one winner, revocation/supersession contention, real-clock expiry
after issuance, a dying process injecting a partial journal frame, and a committed transition whose
process exits before returning its response. Partial-frame injection proves format/restart handling;
it is not instruction-level fault injection into each production fwrite. Rejected consumption leaves
the journal unchanged. Completion without worker evidence refuses.
