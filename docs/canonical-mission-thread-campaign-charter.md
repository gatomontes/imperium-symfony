# Canonical Mission Thread and Authority Provenance campaign charter

Campaign maxim: *In imperium fidimus.*

This strictly local campaign establishes one explicit Operator-originated mission as the
authority root for a harmless inspection of an immutable repository snapshot. Every
consequential act must answer: **which exact mission grant authorizes this act?**

The reference mission examines one exact commit SHA for unauthorized authority derivation and
produces a bounded findings dossier. It may read fixture-controlled repository material and write
only mission records, evidence, results, and receipts beneath its isolated local state root. It
must not modify the inspected target, remediate a finding, use credentials, invoke a provider,
access a network, or publish remotely.

Readable lineage, historical approval, object possession, service construction, deterministic
output, prior admission, issuer competence, and consumed native-transition authority are evidence
or context, never mission authority.

The campaign ends locally after Batches 0–6, a passing complete PHPUnit suite, a terminal audit,
a completion handoff, and a clean worktree after the final local commit. No live trial or Batch 7
is authorized.
