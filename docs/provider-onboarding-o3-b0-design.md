## Implemented refinements

The lower-level GET/POST exchange is private. Operational dispatch reaches only GET; a privileged reflection test exercises POST serialization, options, preflight and parsing against a mock without constructing any authority state. There is no positive O2 cognition bridge. Public TokenEvidence and Tariff instances are structural projections for components, never authenticated certificates. A later competent producer must derive their facts from original evidence before connecting cognition. AccessAdapter.select refuses the missing authentic O1 projection.

KeySource remains fixed deployment infrastructure. Its public generation lookup and EvidenceVerifier.access must be pure local checks suitable for the already-held aggregate lock; secret retrieval occurs only in withKey outside that lock. No environment/vault lookup, concrete live account verifier or real key is selected by default. ProcessCapability is a named, non-serializable identity object recognized only by the runtime's private WeakMap; constructing a lookalike confers no right.

The response guard checks the known key in original bytes and decoded JSON strings/member names, covering JSON-escaped echoes without rewriting original evidence. This does not detect every possible encoding or transformation of sensitive data and is not a general secrecy classifier. The fixed request shape keeps keys out of prompts and durable records. Envelope paths reject dot segments, symlinks and Windows directory junctions (whose PHP is_link result alone is insufficient). A constructor-only publication observer supports deterministic storage interruption tests; it is not request ingress. The sole authority journal and its lock are unchanged.
