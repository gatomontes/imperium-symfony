instance/citadel/source/current authority; adapters verify configuration, credential refs,
expiration and mappings. Those checks are reused without weakening provenance pins. None
fills the missing external factual authority. Stale, foreign, conflicting or absent
originals continue to refuse through accepted owners. No new boolean approval domain exists.

access oracle recognizes a synthetic account schema; it demonstrates transport wiring,
not any production entitlement. Existing O5 full journeys remain synthetic as well.
