The v2 Runner owns every observation. CaseProfile creates the eight finite
synthetic snapshots with full input, mutation/replacement, plan, auxiliary
reference payload and expectation records. Reference digests derive from those
retained payloads. Every case passes through the actual read-only runtime
classifier/transaction validator; no caller result is accepted. Matrix roots
bind ordered input, expectation and observation digests. Output remains
CANDIDATE_NOT_VERIFIED, never closure evidence.

LocalSourceCapture reads only explicit tracked files and Git objects, requires
clean exact HEAD and identical checkout/blob bytes, retains commit/tree/blob
membership evidence and refuses normalization or incomplete source. The CLI
loads only a finite explicit source list and no Composer/environment bootstrap.
Graph scope includes the local Git capture and package writer; native PHP and
Git remain explicit trusted dependencies, not an unbounded capability proof.

PackageStore reserves a new child directory before case execution. Exclusive
file creation, complete writes, flush/fsync and a final raw-file-digest manifest
prevent overwrite and reject incomplete pairs. There is no retry or cleanup in
production. Directory-entry durability is platform-dependent: after a crash,
missing finalization refuses; it does not prove absence of execution. Existing
reservations refuse even when empty. The CLI confines destinations outside the
repository; no runtime directories are selected or touched.

Payload exclusion checks bounded nested/split/hex/base64/percent forms. Source
bytes are a separate pinned public-source domain; scanning PHP literals as
evidence would confuse security refusal patterns with actual payload secrets.
The later independent verifier must enforce the exact finite payload profile,
source membership and trusted source pins in addition to independent exclusion.
No live secret is used as a negative test and no offending value is logged.
