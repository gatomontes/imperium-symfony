## Stage sequence

### Preparation Batch 0 — derivation authority and revocation-race inventory

Inventory every decision, grant, capability, source record, construction path,
lock and call site that could authorize reconciliation-authority issuance.
Demonstrate the current unguarded `issue(admissionId, at, expiresAt)` path and
the exact resolve -> revoke -> consume counterexample. Trace reusable
Operator Root/Imperator issuance-authority patterns, present-tense lifecycle
checks, atomic consumption, interruption recovery, reconstruction and canonical
consumer wiring. Documents and a documentary guard only.

### Batch 1 — issuance authority and at-use currentness contracts

Define the exact derivation act, issuer competence, target, holder, scope,
freshness, revocation, typed custody, single-use consumption and reconstruction
contracts. Historical approval, source provenance, service possession and a
consumed transition authority must be explicitly non-authorizing.

### Batch 2 — rooted issuance decision, custody and atomic consumption

Implement the smallest acyclic Root/Imperator-provenanced decision and typed
issuance capability. Atomically consume it with deterministic reconciliation
authority and issuance-evidence publication. No provider edge.

### Batch 3 — issuer enforcement and revocation-at-use integration

Require the typed issuance capability at the public issuer boundary, remove
unguarded construction paths, and revalidate Root/principal currentness inside
the same governed use cut before derivation or claim publication.

### Batch 4 — adversarial, application, concurrency and interruption proof

consumed transition authority; resolve -> revoke -> consume; expiry; competing
issuers and claimants; interruption cuts; fresh processes; container/application
wiring; reconstruction; and absence of provider/credential/network edges.

### Batch 5 — separately sequenced terminal audit

decision-to-issuance-to-consumption-to-recovery chain, run focused and full
tests, retain exact-SHA GitHub CI evidence and decide bounded closure without
restoring Batch 7.
