Define finite whole-record/history bounds before implementation, including referenced originals and index reconstruction work.

Keep the initialized `profile_designations` extension's exact five top-level keys: schema, initialization, delegations, events, current. Put required signed records, receipts and attestations within the approved collections using explicit closed shapes. Do not silently add keys or reinterpret an existing schema. Absence, unknown shapes, incomplete history or a corrupt event-derived index refuse. Validate signed initialization as historical evidence; its empty collections grant no current authority.

Each key is exact parent/Formation/steward/target. First event generation is 1 only for verified vacancy; successors name the last event and increment one, including after terminal states. Keep tombstones and immutable history; refuse duplicates, gaps, overflow and pruning. The current index must equal a deterministic reconstruction from signed events, not become a second truth source.

Initial designation follows exact competent approval. Live-predecessor replacement requires exact `lineage.supersedes`; atomically retain predecessor supersession and successor `current_active` attestations in the same journal commit, linked to the act and prior attestations. Follow the [generic attestation contract](../contracts/profile-attestation.schema.json). Revocation advances the event history, retains its terminal attestation and clears current use without choosing a replacement. Expiry refuses at the observed clock without a read-side grant. A successor after revocation/expiry preserves the terminal fact and last event; it must not relabel that predecessor superseded. Validate an expired predecessor historically when recording a later legitimate terminal transition; never renew it by skipping current checks on the new act.

Exact retained signed request replay returns the historical receipt before stale-head/time checks. Changed bytes under an already used scoped nonce conflict. Historical recognition cannot restore currentness. Two acts signed at one head have at most one publication, including unrelated intervening journal changes.
