All process barriers use attempt/held/release/result files with bounded 30-second
waits and native exits. An independent nonblocking lock probe proves Formation
is held; a second process cannot publish before release. Sleeping is polling,
never the serialization proof. The test-only rename adapter calls the real
rename and has no runtime authority effect. Invalid-custody tamper cases are
negative fixtures and never substitute for positive native producers.

Public originals distinguish actual institutional signatures/model-preparation
acts from explicitly unverified external model/version/access/cognition facts.
Counts, platform skips and errors belong to the report's exact final run; earlier
targeted runs are supplemental diagnostics, never substituted for complete CI.
