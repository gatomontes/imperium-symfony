# PPC2 native writer and fence inventory

Scope is the source reachable from the nine `FormationInstitution::SEATS` incumbents, their installation/occupancy originals, Formation target appointments, and alternate native authorities that can supersede the meaning of those originals. This is a source inventory for a **partial** result, not an accepted synchronized-writer deployment set. No native writer was changed or newly admitted by PPC2. There is no claimed exhaustive proof for arbitrary generic filesystem callers, old executables or administrative writers.

The installation adapter reads every JSON in the role's Office occupancy directory, requires an intact matching ACTIVE record and exact intact installation original, and requires exactly one matching actor. It refuses unsupported installation IDs with `CMF123_GOVERNED_SUCCESSOR_ADAPTER_REQUIRED`. It has no package-completion marker: a multi-member package interrupted after some placements may leave an individually intact subset. Missing required actors make candidate verification fail, but this is not proof of package-level atomic installation or recovery. No broader recovery authority is created here.

## Other storage paths inspected

`AuthorshipResidentSeatBindingService` only selects hagiography/studium, and `ArtificerSeatBindingService` selects foundry.artificer; those are outside the nine consumed roles. `OperationalManifestationSeatBindingService`, `ModelBoundOperationalManifestationSeatBindingService` and `DelegateMissionOperationalManifestationSeatBindingService` write mission/operational occupancy, not the consumed Office installation paths. Garrison custody/return services write custody and terminal receipts; Senate witness retirement writes examination/custody records. They read Office incumbents but do not replace their installation/occupancy originals. Generic `ImmutableRecordStore`, `RecordReferenceValidator`, `AtomicTransition` and native/Formation journals were included in the storage-boundary search; these helpers confer no designation competence.

Searches covered `src` for installation/occupancy literals, occupancy directory properties, binding/installation/successor/retirement service names, publication calls and indirect NativeBoundary/StateStore owners. The public evidence retains the reproducible search output. A positive PPC2 synchronization acceptance requires completing executable call-graph/lock-order proof for this entire supported set; that acceptance is **not supplied** by the inventory.

## Remaining implementation obligation

Wrapping Constable with Formation while leaving `StateStore::locked`/V0 ordering unchanged can introduce a cycle; globally wrapping NativeBoundary with Formation would instead make the existing root installation callback reacquire a non-reentrant Formation lock. The solution must move the shared outer boundary at actual owners and pass an already-held frame, then prove indirect historical paths and interruptions. Changing the pinned AtomicTransition, adding an unsynchronized incumbent registry, or asserting that a raw snapshot is synchronized is not a solution. This run leaves those owners unchanged and keeps current assignment evidence unavailable.

FRESH first requires a vacant native root. Establishing native institutions first violates that vacancy; founding first makes later root installation refuse `B225_FRESH_ROOT_OWNED` (and the legacy root owner does not recognize onboarding v4). Component tests use actual native installation in disposable roots without claiming combined FRESH establishment. No installed state was inspected.
