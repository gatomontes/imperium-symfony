# Delegate mission Profile-candidate derivation and return

Step 12 consumes the exact Step 11 derivation authority to elaborate and seal one versioned mission-specific Delegate Profile candidate.

Derivation is bound to the immutable Profile scope, exact Persona, current occupied Alchemist, Imperator limitations, reservation, and unchanged live `ADMITTED_HELD` Garrison custody. The candidate preserves the complete duration, resource, stop, return, unbinding, custody-restoration, and retirement design.

The candidate is returned to Conscription at `DELEGATE_MISSION_PROFILE_CANDIDATE_RETURNED_PENDING_CONSCRIPTION_INTAKE`. The return opens only one single-use intake-disposition authority. Neither artifact grants approval, activation, installation, examination, assembly, Seat binding, deployment, operational use, resource access, external action, or execution authority.
