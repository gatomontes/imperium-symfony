# Oracle governed research

Augur has no standing model-research authority. An exact, sealed Imperator authorization may create one bounded Oracle research commission naming providers, destinations, permitted claim subjects, tools, capabilities, source count, budget, validity window, and return contract.

External cognition occurs only as a disposable sortie through Iron Gate. Its raw return enters only through Lazaretto. Oracle may admit evidence only when the sanitized artifact preserves the exact authorization, commission, sortie, manifestation, sources, payload digest, and transformation lineage and every returned claim remains within scope.

Admission consumes the commission at `ORACLE_RESEARCH_EVIDENCE_ADMITTED_AUTHORITY_CONSUMED`. The admitted artifact grants no continuing research, credential use, provider invocation, eligibility, recommendation, selection, assignment, Profile mutation, deployment, or execution authority.
