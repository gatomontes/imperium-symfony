# Delegate mission model selection

Step 61 assigns selection exclusively to the occupied Seneschal. Curia may select the Oracle recommendation, select another frozen eligible candidate, reject all candidates, or return a new commission. It may not select a model outside the frozen eligible set.

Successful selection opens only one exact Conscription binding-seal authority. It does not assign or invoke the model, mutate the Profile, release credentials or resources, authorize external action, or execute.
