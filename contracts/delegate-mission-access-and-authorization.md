# Delegate mission access attestation and authorization

Step 63 lets Clavium attest factual access to the exact bound provider/model version using sealed, expiring evidence without disclosing or releasing credentials. Step 64 lets Imperator authorize or refuse the exact attested provider invocation and frozen turn-one requirements.

Authorization opens only one scoped Clavium activation authority. It does not itself release a credential, invoke the provider, release resources, authorize external action, or execute cognition.
