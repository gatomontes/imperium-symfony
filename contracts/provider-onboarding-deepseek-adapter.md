## Transport, attribution and settlement

The actual HTTP boundary constructs Authorization only inside custody and sends the exact prepared bytes once. Test the real HTTP options through a mock client/recording transport. Limit the entire response to 1,048,576 bytes, including incremental reads; whitespace/keepalives cannot reset the total deadline. Bound connecting and reading within 10,000 ms for access or 60,000 ms for cognition and within original authority expiry. Prove configured behavior with a deterministic clock and transport harness; no external endpoint is called.

Provider JSON is untrusted. Reject invalid UTF-8, duplicate keys, malformed/truncated bodies, unsupported response variants, invalid types/bounds and contradictory model/usage/finish information. Define versioned closed consumed projections and an explicit policy for unsupported extensions; never silently treat absent usage as zero. Preserve original bytes and distinguish provider fields from locally derived request/operation attribution. Provider responses need not echo a local operation digest: trusted dispatch associates the exact retained operation with its received bytes; a provider-supplied echo or idempotency header cannot prove that association or exactly-once behavior.

Decode provider response identity, actual model/fingerprint, finish reason and complete usage. Check prompt = cache-hit + cache-miss and total = prompt + completion when these meters are required by the admitted evidence; account for reasoning within completion, not twice. Use checked integer micro-USD arithmetic and evidenced rounding/tariff validity. No assumed cache benefit, free access or unknown fee. GET listing proves only the scoped observation, never invoke entitlement. Missing provider response ID or required attribution must be handled by an explicitly typed local observation mapping; never fabricate a provider-issued ID.

Retain the closed O2 envelope unchanged through fixed infrastructure storage: metadata is {provider_response_id,operation_digest,response_digest,usage,provenance}; envelope is {claim_ref,operation_digest,response,metadata}. Any richer public HTTP evidence requires an explicitly documented immutable mapping to these fields, preserving raw bytes and provenance without weakening the decoder. The adapter provenance is a fixed local identity bound to the operation, not trusted model text. Source-specific validation remains required before settlement.

Response retention is atomic, immutable by claim and fixed-root/path-safe. Same original replay is idempotent; contradictory bytes refuse. Prevent symlink/path traversal and concurrent overwrite. Retain outside the aggregate lock only after the O2 metadata checkpoint. Recovery reads the original envelope and never issues, consumes, dispatches or reconstructs evidence from caller text. If a response contains sensitive authentication material, refuse public retention without rewriting bytes into purported original evidence; keep uncertainty/exposure.

The safe-retry allowlist remains empty. HTTP 429/500/503, connection exceptions, timeouts, lost acknowledgements, cancelled reads and provider retry advice never authorize another call. Distinguish pre-admission refusal from post-reservation unknown outcome. After an uncertain dispatch, retain maximum exposure and the source fence even after expiry or a new command/policy. Only complete attributable original evidence with trustworthy usage may settle. A final invalid assessment may be terminal, but absent usage cannot release exposure. No promise of remote cancellation, zero billing after timeout or power-loss durability.
