# Delegate mission model binding

Step 62 permits only the ordinary Recruiter to seal Curia's exact selected provider/model version and configuration to the exact Delegate Manifestation, mission Seat, bounded commission, occupancy generation, and turn 1.

The binding is not Profile mutation or model assignment. It opens only a single-use Clavium access-attestation authority and grants no credential, provider invocation, resource, external-action, or execution authority.
