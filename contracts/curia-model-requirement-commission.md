# Curia Model Requirement Commission

Curia defines the cognitive need; it does not name or select a preferred model. An occupied Seneschal may issue one immutable commission for an exact Office Seat or mission function against one exact canonical Oracle catalogue snapshot.

The commission binds the task, required and prohibited capabilities, tools, context minimum, information classification, residency, permitted providers, cost, latency, reliability, fallback, explicit prohibition on silent substitution, evaluation rubric, evidence threshold, validity window, and exact target.

Augur may accept the commission without changing its meaning. Acceptance stops at `CURIA_MODEL_REQUIREMENT_COMMISSION_ACCEPTED_PENDING_ORACLE_EVALUATION` and grants no research, eligibility evaluation, recommendation, selection, assignment, Profile mutation, provider invocation, deployment, or execution authority.
