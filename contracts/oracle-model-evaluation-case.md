# Oracle model evaluation case

An accepted Curia Model Requirement Commission authorizes only the mechanical opening of one evaluation case against its exact canonical catalogue snapshot. Opening freezes the candidate universe and may exclude entries only through explicit mechanical gates: permitted provider, `ACCESSIBLE`, `ADMISSIBLE`, and the commission's minimum evidence-source threshold.

Every surviving exact provider/model/version receives one single-use eligibility-finding authority bound to the unchanged Curia criteria, catalogue digest, evidence sources, and claims. An empty candidate set returns to Curia rather than weakening requirements.

The normal checkpoint is `ORACLE_MODEL_EVALUATION_CASE_OPENED_PENDING_AUGUR_ELIGIBILITY_FINDINGS`. Opening consumes the case-opening authority and grants no finding yet, research, ranking, recommendation, selection, assignment, Profile mutation, provider invocation, deployment, or execution authority.
