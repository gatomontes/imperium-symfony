# Oracle Augur founding activation

Oracle is a permanent Citadel Office, but it is not part of the closed Operator-root installation. Its resident Augur must enter through governed personnel production, Garrison admission, standing Profile approval, Conscription assembly on the canonical generic Officer substrate, and atomic Seat binding.

The first Augur presents an unavoidable bootstrap boundary: Augur cannot select the model required to create the first functioning Augur. Imperator may therefore approve one exact provisional founding assignment under an exact Charter reference and a digest-valid Clavium access assertion. That authority is consumed by the assignment and grants Augur no self-selection power.

Conscription may activate Augur only from the exact provisional assignment, an available `ADMITTED_HELD` Persona custody record, a current Imperator-approved standing Profile bound to that Persona and model assignment, an authorized occupied Recruiter, and the canonical generic Officer substrate.

The terminal checkpoint is `ORACLE_AUGUR_BOUND_ACTIVE_NO_MODEL_SELECTION_AUTHORITY`. Augur receives only model-intelligence stewardship and catalogue-snapshot authority. Research, recommendation, selection, reassignment, Profile mutation, credential disclosure, provider invocation, deployment, and execution remain closed. Replacing the provisional founding model requires a later governed Oracle evaluation and atomic cutover.
