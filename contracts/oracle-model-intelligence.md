# Oracle model-intelligence ledger

Oracle is Imperium's standing model-intelligence Office. Augur is its permanent, mission-independent Officer.

The ledger separates three facts that must never collapse into one mutable list:

1. **Known** — Oracle has attributable evidence that an exact provider/model/version exists and records every material claim against its source evidence.
2. **Accessible** — Clavium, acting through Locksmith, has supplied an opaque provider-access assertion. Lack of access does not erase knowledge.
3. **Admissible** — an explicit policy evaluation classifies the exact model version as `ADMISSIBLE`, `RESTRICTED`, `INADMISSIBLE`, or `UNEVALUATED`. Accessibility does not imply admissibility, and admissibility does not imply accessibility.

Every source, claim, digest-valid access assertion, policy reference, classification, actor, exact model version, prior snapshot, generation, and snapshot digest remains reconstructable. Snapshots are immutable and later snapshots cite their exact predecessor. Canonical snapshots terminate at `ORACLE_CANONICAL_CATALOGUE_SNAPSHOT_SEALED_NO_SELECTION_AUTHORITY`. Credentials and secret material never enter Oracle.

The original ledger boundary was `ORACLE_MODEL_INTELLIGENCE_SNAPSHOT_SEALED_NO_SELECTION_AUTHORITY`; the canonical catalogue supersedes it with the stronger provenance-bound checkpoint above. It creates no Curia requirement commission, research, eligibility determination, recommendation, selection, assignment, Profile mutation, provider invocation, silent substitution, deployment, or execution authority.
