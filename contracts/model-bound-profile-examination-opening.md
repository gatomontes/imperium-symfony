# Model-bound Profile examination opening

The occupied Lord Speaker may open a Senate examination only for the exact immutable Profile revision whose model binding has a sealed ACCESS_AVAILABLE Clavium attestation.

The case preserves the Profile ID, version, digest, destination Seat, exact model configuration, constraints, fallbacks, approved dossier lines, Mission Authorization, Imperator review, Conscription binding, Clavium access evidence, and access restrictions. The fixed panel is Trust, Security, and Usability.

Opening issues one sealed commission to each exact committee Seat. Each commission must be independently accepted before testimony or questioning becomes exercisable. Opening itself authors no question, accepts no testimony, makes no finding, begins no deliberation, and grants no Profile approval, installation, current/active designation, credential use, invocation, deployment, or execution authority.

The checkpoint is PROFILE_EXAMINATION_OPENED_PENDING_SENATOR_ACCEPTANCE.
