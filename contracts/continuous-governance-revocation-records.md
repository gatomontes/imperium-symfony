# Continuous-governance revocation records

Batch 6 defines two separately versioned schemas. Batch 7 implements one narrow internal
`INTERRUPT` disposition issuer for a durable, pre-I/O governance cognition invocation claim;
no enforcement-authority issuer or consumer exists.

That disposition is an attributable judgment only. It cannot mutate state or open enforcement
authority. A future competent issuer must separately create one exact, expiring, single-use
enforcement authority bound to the disposition, enforcer, affected scope, and permitted native
transition. Judgment therefore cannot directly mutate state.

The enforcement-authority schema grants no continuing, external-action, or perimeter authority.
No record conforming to either schema exists merely because the schema exists.
