# Imperator planning-dossier review

Imperator reviews one exact sealed dossier rendered as a single consecutive numbered list. `APPROVE_DOSSIER` requires acknowledgment of every line in that exact dossier version. `OBJECT_RETURN_FOR_REVISION` must cite one or more plain line numbers and binds each citation to the original line text and digest.

Approval consumes review authority and opens only Mission Authorization derivation authority; it is not execution authority. Objection consumes review authority, blocks advancement, and opens a bounded revision authority for the competent proposal owner (Citadel for new missions, Curia for its existing mission) carrying the cited lines. The original dossier and its numbering remain immutable evidence. Any revision is a new version and digest.

Existing Curia-specific runtime revision authorities require a reviewed mapping
before Citadel reuse. This mission-proposal review does not replace the earlier,
separate Imperator approval required to begin drafting under /contracts/citadel-mission-intake.md.
